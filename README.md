# Labyrinth of Refrain: Coven of Dusk — PS Vita English Script Port

An unofficial adaptation of the Nintendo Switch English localization for the Japanese PS Vita release, **PCSG00795**, retaining Vita's controls and gameplay rules.

**Current release: R22 — message, objective and location fixes (test release).** The patcher applies the complete patch in one step; no earlier patch is required.

## Downloads

- [R22 patcher](REFRAIN_VITA_R22_ANDROID_EN.zip) — approximately 18.2 MB, compressed ZIP.
- [Historical R15 story comparison](HISTORIA_ADAPTADA_JP_SWITCH_VITA_R15_VWF02.csv): records the 476 previously adapted passages. Its “English text used” column describes R15, not the current patch. **Contains story spoilers.**

## Requirements

- The Japanese PS Vita game, **PCSG00795**.
- VitaShell and an installed, enabled rePatch plugin.
- A recent Chromium-based browser, including Chrome on Android.
- These two clean original files, copied from the original game folder opened as decrypted in VitaShell:

| File | Exact size |
| --- | ---: |
| Decrypted `Media.psarc` | 1,473,994,740 bytes |
| Original VitaShell `eboot.bin` | 2,953,792 bytes |

You do not need the Switch archive. Do not select files generated by an earlier patch.

## Patching and installation

1. Extract the patcher ZIP and open `REFRAIN_VITA_R22_ANDROID_EN.html`.
2. Select the two original files and click **Verify files and create patch ZIP**.
3. Keep the tab open until the download finishes. The resulting ZIP is approximately 1.38 GiB. Keep enough space for the originals, the ZIP and the extracted files.
4. Back up any existing `ux0:rePatch/PCSG00795/` folder.
5. Extract the generated ZIP and copy its `rePatch` folder to `ux0:`. Install **both files**, even if an earlier version is already installed:

```text
ux0:rePatch/PCSG00795/Media.psarc
ux0:rePatch/PCSG00795/eboot.bin
```

6. Launch the game with rePatch enabled.

The generated `Media.psarc` is **1,475,422,167 bytes**. It is larger than the original because R21 adds dialogue pages. The small downloadable patcher ZIP and the approximately 1.38 GiB generated game patch ZIP are different files.

The patcher runs locally and does not upload or modify your selected originals. Keep the original game installation intact. To uninstall, remove the patch's PCSG00795 folder from rePatch. To roll back, restore your previous complete rePatch folder.

## Included content

- English story and exploration dialogue.
- Translated menus, messages, items, equipment, skills, Donum, Pacts, requests, quests and dungeon descriptions.
- Official localized graphics adapted to Vita, retaining Vita button icons.
- English opening, PuppetShow scenes and credits artwork.
- Proportional letter spacing, font adjustments and expanded names where space allows.

## What changed in R22

- Fixes one-line blue notices that could display only a fragment, such as “A”.
- Fixes objective text mixed with numeric IDs by correcting the affected table fields throughout the objective and notice groups.
- Reviews all **132 objectives**, **254 event notices** and **181 signs** for the same formatting problem; objectives fit within three lines.
- Cleans up malformed location and transfer names, including Melm and Astrom labels.
- Removes alignment padding from **148 message entries**, including the Give Up / return-as-defeated confirmation.
- Retains the Workshop logo and simplified public patcher interface.

R22 includes the complete R21 story restoration and all earlier fixes. Apply it directly to clean original files; no earlier patch is required.

## Story restoration retained from R21

- Restores the complete supplied official English wording of all **476 previously adapted story passages**, across **161 scripts**.
- Uses additional dialogue pages where needed: **324 added pages compared with R18**, or **322 compared with R20**.
- Retains the original voice triggers without repeating them on newly added pages.
- Includes the later font, punctuation and spacing corrections.
- Retains the shop texture fixes, the corrected Silver display, the aligned puppet-repair material message and the Vita button graphics for field skills.


## Limitations

- The 476 passages in the historical adapted-story catalogue have been restored in R21. Other interface labels and names may still be shortened or rephrased to fit Vita's screens.
- Original Vita tutorial images are preserved and may contain Japanese interface labels.
- Original Japanese voices and audio remain unchanged.
- Vita-specific gameplay values, controls and instructions are retained where they differ from Switch.
- Only **PCSG00795** with the specified original files is supported. Other regions and revisions have not been validated.
- **R22 is a test release.** Its table fixes passed checks using the original Vita text parser and the actual HTML patcher. Visual confirmation of these R22 fixes on Vita is still pending.
- Additional dialogue pages have worked on Vita in the unvoiced Dronya hair-description test and in a later Luca scene involving an alchemy cauldron. These reports do not constitute a complete playthrough or confirmation of every voiced scene.
- The retained R21 restoration passed text-layout, script-preservation and archive-structure checks, including independent reading of all 161 expanded scripts. The complete patch has **not received a full Vita playthrough**. Keep a backup of your previous working patch.

## Historical story comparison CSV

The linked R15 CSV records the 476 passages before their R21 restoration. It is retained for historical comparison and is **not a list of remaining story cuts in R22**. It has three columns:

| Column | Content |
| --- | --- |
| 1 | Original Japanese text from the Vita edition |
| 2 | Official Switch English text |
| 3 | English text used by the R15 Vita patch |

It includes dialogue line breaks and uses UTF-8 encoding. Menus, item names and text contained in images are outside its scope.

## Reporting an issue

Include the patch version, location or scene, reproduction steps and a screenshot. For text issues, quote the visible line. For a crash, include the Vita error code, error dump if available, the last visible dialogue and the exact point where it occurs. Please also mention whether Auto or skip was active. Restore your previous complete patch pair if necessary.
